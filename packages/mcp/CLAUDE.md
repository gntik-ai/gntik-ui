# packages/mcp — gntik-ui MCP server

The MCP server agents use to build with gntik-ui. Tools, transports, deployment and the generated
files are documented in `README.md`; repo-wide rules are in `/AGENTS.md` and `/CLAUDE.md`.

- Sources of truth it reads: `registry.json` (catalog) and `kit-registry.json` (installable items),
  both generated by `pnpm registry` (scripts in `scripts/`, `--check` in CI).
- 16 tools: the catalog tools plus `list_kit`, `get_component`, `get_block`, `get_template`,
  `scaffold_page`, `scaffold_preset`. Keep texts in English; prompt names `remaquetar` and
  `preparar_producto` stay for compatibility.
- Gate: `pnpm --filter @gntik-ai/gntik-ui-mcp test` and `smoke`.
