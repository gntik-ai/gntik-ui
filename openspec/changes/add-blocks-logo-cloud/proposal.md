# Add LogoCloud

## Why

Public pages have no kit block for customer social proof. LogoCloud supplies a static row or grid of single-colour customer marks without animation, blur or mask effects.

## What Changes

- Add LogoCloud, its public props and item types, metadata, neutral SVG fixtures and exports.
- Add English and Spanish default captions through the ui i18n catalog.
- Add live gallery examples for row, grid, caption placement, Hero composition, overrides and empty input, plus accessibility tests.
- Regenerate registry output and add one minor blocks/ui changeset.

## Impact

- Capability: blocks/logo-cloud (ADDED). Risk R1.
- No changes to Hero, the landing template, tokens or existing component behaviour.
- No linked, raster, original-colour or animated logos. No publishing or deployment.
- Revert this ChangeSet or pin previous package releases to roll back.
